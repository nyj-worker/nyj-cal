## 실행 및 로컬 구동

Node.js 22.12 이상(현재 환경은 24)을 사용합니다.

```powershell
npm install
npm run dev -- --port 5173
```

브라우저에서 http://127.0.0.1:5173/ 에 접속합니다.

```powershell
npm test
npm run build
npm run preview -- --port 5173
```

빌드 결과는 `dist/` 및 GitHub Pages 배포용 `docs/` 폴더에 자동 생성됩니다.

## 실제 엑셀 가져오기 및 GitHub 동기화

1. **엑셀 파일 업로드**를 누릅니다.
2. 파일을 드롭하거나 **파일 선택하기**에서 엑셀 파일(`.xlsx`, `.xls`)을 선택합니다.
3. 동일한 이름의 파일이 이미 보관되어 있을 경우:
   - **기존 파일 교체 (덮어쓰기)**: 기존 파일을 새 파일로 갱신하고 GitHub에 자동 푸시
   - **기존 파일명을 수정하여 저장**: 새 파일명을 입력하여 별도 파일로 보관 및 GitHub 푸시
4. 저장 완료 시 `event/` 폴더 저장 및 GitHub 원격 저장소(`main/event`) 자동 커밋/푸시가 한 번에 이루어집니다.

제공된 `주간행사계획_20261019_20261025.xlsx`는 시장·부시장 24건, 교통국장 5건, 총 29건으로 인식됩니다.


## 사용

- 상단 주차 선택으로 보관된 주차를 전환합니다. 좌우 화살표는 이전·다음 **저장 주차**로 이동합니다.
- **이번 주**는 한국 날짜 기준 현재 주차로 이동합니다. 저장된 현재 주차가 없으면 업로드 안내가 표시됩니다.
- 카테고리 탭, 행사명·장소·주관부서 검색, 참석자 다중 선택, 시간대 선택을 함께 사용할 수 있습니다. 여러 참석자는 OR 조건입니다.
- ‘부시장’ 칩은 제1·제2부시장 및 직위 번호가 없는 부시장 모두를 포함합니다. ‘시장’과 혼동하지 않습니다.
- 시간표는 09:00~18:00입니다. 종일·미정, 시간축 밖 일정, 자정에 걸치는 일정은 ‘종일 / 기타’에 표시합니다.
- 같은 시간대의 행사는 가로로 나뉩니다. 짧거나 밀집된 일정은 목록 보기 또는 상세 팝업에서 전체 내용을 확인하세요.
- 일정 클릭으로 상세 정보, 구글 캘린더 추가 링크, 텍스트 복사를 사용할 수 있습니다. 구글 링크는 새 캘린더 작성 화면을 열고 최종 저장은 사용자가 합니다.
- JSON·ICS는 선택 주차의 **전체 행사**를 내보냅니다. 검색·필터는 내보내기 데이터에 영향을 주지 않습니다.
- 인쇄/PDF는 **현재 검색·필터를 적용한** 주간표를 출력합니다. A4 가로 전용 표에서 행사명을 줄이지 않고 표시합니다. 기본 샘플과 제공 파일은 한 장을 목표로 구성했으며, 매우 많은 행사·긴 텍스트는 인쇄 배율 조절 또는 추가 페이지가 필요할 수 있습니다. 브라우저 머리글·바닥글을 끄면 더 넓게 출력됩니다.

## 저장 방식

- 행사와 주차 히스토리: IndexedDB `weekly-governance-v1`, `weeks` 저장소.
- 마지막 주차·검색·필터·보기 방식: localStorage `weekly-governance-view-v1`.
- 주차 키는 해당 주의 월요일 날짜(`YYYY-MM-DD`)입니다. 표시상의 월 주차는 월요일 날짜를 1~7일, 8~14일 등으로 나눈 순번입니다. 날짜 범위가 최종 기준입니다.
- 저장 실패 시 화면에 오류가 표시됩니다. 업로드 저장은 하나의 트랜잭션으로 처리해 일부 주차만 덮어쓰는 일을 방지합니다.
- 저장 데이터는 **같은 브라우저·같은 프로필·같은 접속 주소(호스트와 포트)**에서 유지됩니다. 브라우저 사이트 데이터 삭제·시크릿 모드 종료 시 지워질 수 있으므로 필요하면 JSON을 별도 보관하세요. JSON은 내보내기용이며 이 버전의 가져오기는 엑셀을 지원합니다.

## 파싱 규칙

- 시트명에서 시장·부시장 / 교통국장을 구분합니다. 다른 시트는 무시합니다.
- 1~3행 헤더를 우선 인식하며 최대 12행까지 탐색합니다. 동의어 및 유사도 매핑을 사용합니다.
- 상하·좌우 병합 값을 복원하고 동일 시트 내 완전히 동일한 행사 값은 중복 제거합니다.
- 날짜 열 또는 월·일 분리 열, 엑셀 날짜 숫자(1900/1904), `2026.10.19`, `10/19(월)` 등을 지원합니다.
- 연도는 파일명의 8자리 날짜 또는 시트 안의 전체 날짜를 근거로 보정합니다. 연말·연초는 기준 주간에 가장 가까운 연도를 사용합니다. 근거가 없으면 현재 한국 연도를 사용하고 경고합니다.
- 시간 숫자(`0.3958333` → `09:30`), `09:30`, `0930`, `오후 2시 30분`, 시작~종료 범위를 지원합니다. 불명확한 시간은 미정으로 유지합니다.
- 종료 시간 누락은 시작 1시간 후로 설정하며 화면과 내보내기에 자동 설정임을 명시합니다.
- 참석 열이 없는 시장·부시장 시트는 비고의 직위 표현을 읽습니다. 교통국장 시트의 참석 `O`는 교통국장으로 변환합니다. 번호 없는 ‘부시장’은 번호를 추측하지 않고 그대로 보존합니다.
- 여러 주차가 들어 있으면 분리 저장합니다. 한 번 선택한 여러 파일에서 주차가 겹치면 마지막 선택 파일을 사용하고 안내합니다.

## 핵심 파일

```text
src/App.tsx                         전체 화면·필터·주차 전환
src/components/WeeklyCalendar.tsx   주간 시간표·목록·인쇄 표
src/components/UploadModal.tsx      드롭·미리보기·교체 확인
src/components/EventDetailModal.tsx 상세 정보·복사·구글 링크
src/lib/excelParser.ts              시트·헤더·날짜·시간 정규화
src/lib/storage.ts                  IndexedDB 트랜잭션·조회 상태
src/lib/calendar.ts                 필터·시간 겹침 배치
src/lib/export.ts                   JSON·RFC 5545 ICS 생성
tests/                             실제 파일·예외·저장·업로드 검증
```

엑셀 파서는 업로드 창을 처음 열 때 별도 청크로 로드하여 초기 화면을 가볍게 유지합니다. 외부 폰트·원격 데이터 요청은 사용하지 않습니다.
